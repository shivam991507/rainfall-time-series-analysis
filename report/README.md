# Original academic report

The public project preserves the original report as:

`original_academic_report.pdf`

The report compares Delhi/Haryana/Chandigarh with Assam/Meghalaya, decomposes the rainfall series into trend, seasonal, cyclic and random components, tests stationarity, compares forecasting models, and reports forecasts through 2025.

Only the Delhi/Haryana/Chandigarh raw monthly dataset is currently available for the reproducible Python implementation.
