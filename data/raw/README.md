# Raw data

Place the supplied Delhi-Haryana-Chandigarh source CSV here as:

`delhi_haryana_chandigarh_source.csv`

The Python script extracts only the raw monthly date and rainfall columns and ignores the spreadsheet's precomputed formula/result columns.

The original academic report also analyzes Assam-Meghalaya, but its raw monthly dataset is not currently available, so that series is not reconstructed in Python.
